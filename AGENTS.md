# Agents

Read `CLAUDE.md`. It is the single set of house rules for every coding agent and every person in
this repo, whatever tool they use. Its failure log goes on in `apps/desktop/CLAUDE.md` and
`apps/api/CLAUDE.md`: read the one for the app you touch. Milestone plans live in `docs/plans/`;
start from `docs/plans/TEMPLATE.md`. Run `make check` before reporting done.
